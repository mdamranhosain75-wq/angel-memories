# Angel Memories — Private Gallery

Responsive static frontend concept using a Futuristic Glass + Royal Blue & Gold visual theme.

## Preview features
- Responsive photo and video gallery interface
- Upload previews saved in browser IndexedDB
- Search and photo/video filters
- Album creation preview
- Full-screen media viewer and delete controls

## Important limitation
This is a frontend prototype only. Media stays in the current browser/device. It is not synced, backed up, or accessible from other devices. Authentication, private cloud storage, database-backed albums, sharing permissions, and secure admin roles still need to be implemented before storing private or important memories.

## Deploy on Vercel
Import this repository into Vercel. It is a static site: no build command is required and the output directory is `.`.
